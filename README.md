# BakudanSlim

爆弾を置いて、爆風で飛ぶパズルゲーム（JavaScript / 単一HTML）と、主役のスライムを作る「スライムメーカー」のセットです。

- ゲーム: https://oosawak.github.io/bakudanslim/
- スライムメーカー: https://oosawak.github.io/bakudanslim/slime-maker/

## 遊び方

- 移動: ←→（A/D）
- 爆弾を横に置く: Z または Space
- 足元に置く・積む: ↓
- 起爆（置いた順）: X または ↑
- 爆弾の上に乗って起爆すると真上に、横で起爆すると横に飛びます
- 爆風に当たった爆弾は連鎖して爆発し、連鎖するほど爆風が広がります

## 設計

- 移動はピクセル単位、爆発の解決はセル（配列）単位
- ルール（爆風の届くセル数、連鎖で増えるセル数、持てる爆弾の数など）は、ゲーム画面下の「ルール定義（Markdown）」で変更できます
- 主役は画像ではなく「設定データ」から生成します

## 主役の変え方

1. [スライムメーカー](https://oosawak.github.io/bakudanslim/slime-maker/)で好きなスライムを作る
2. 「このスライムのURL」をコピーする（設定がURL自体に入っています）
3. ゲーム画面下の「主役定義（Markdown）」の「スライムメーカーのURL」に貼って「主役を反映する」を押す
4. タイトル画面とゲーム中の主役が、そのスライムになります

既定の主役は、Pyxel版 OooMaker のスライム（緑の丸＋黒い縁＋点の目）です。
